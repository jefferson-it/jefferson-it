# Jefferson Silva 👋

> Desenvolvedor brasileiro apaixonado por programação, sistemas e tecnologia.

Sou desenvolvedor com foco principalmente no ecossistema **JavaScript/Node.js**, mas também exploro **Rust, Python, Go e outras tecnologias** em projetos pessoais, acadêmicos e profissionais.
